# Hangman Game (Python)

A command-line Hangman game built in Python. The player guesses letters
to reveal a hidden word, with a maximum of 6 wrong guesses before the
game ends.

## Features

- Random word selection from a predefined word list
- ASCII art hangman that updates with each wrong guess
- Input validation (single letters only, no duplicates)
- Win/lose detection with replay option

## How to Run

```bash
python hangman.py
